# European Banking Customer Segmentation and Churn Analytics

An interactive data science and web application project built to analyze, segment, and predict customer churn for European banking clients.

## Key Features
- **Dynamic KPI Metrics**: Track total customers, churn rates, active member ratios, and high-value capital risk in real time.
- **Interactive Segments**: Filter by geography, gender, age brackets, and balance tiers.
- **Core Visual Modules**: Explore overall summaries, geographic risk indices, age/tenure comparisons, and high-value customer drivers via a multi-tab Streamlit dashboard.
- **Granular Drill-Down**: Inspect filtered customer records instantly.
